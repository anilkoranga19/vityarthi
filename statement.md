# Problem Statement

-Users often face difficulty in estimating accurate taxi fares before starting a trip. Fare calculation varies based on distance, waiting time, number of passengers, and vehicle type. This project aims to create a simple and interactive program that accurately calculates the total taxi fare using user-provided inputs.

# Scope of the Project

-The project focuses on calculating taxi fares based on distance, waiting time, trip type (one-way or round trip), and vehicle selection.

-It provides a simple command-line interface for user input.

-It includes fare variations for multiple vehicle categories.

-The project does not include real-time GPS distance tracking, online payment, or map integration.

# Target Users

-Individuals who want to estimate their taxi fare before a ride.

-Students and beginners learning Python and basic input-process-output programming.

-Small taxi service providers who want a simple fare calculation tool.

-Developers who want a base program to extend into a full taxi booking system.

# High-Level Features

-Calculates taxi fare based on distance and vehicle type.

-Supports round-trip fare calculation.

-Includes waiting time charges.

-Uses predefined fare rates for Hatchback, Sedan, SUV, and Premium Sedan.

User-friendly command-line interface for step-by-step data input.

Automatic fallback to default vehicle type if an invalid input is entered.
